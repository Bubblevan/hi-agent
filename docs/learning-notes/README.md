# 我的 Agent 学习笔记

这里记录我跟随 HelloAgents 学习、实现和验证 `hi-agent` 的过程。代码负责回答“现在能不能工作”，笔记负责回答“我为什么这样设计、哪里还没理解、下一步准备怎么实验”。

## 推荐记录方式

每完成一个小节，就在对应章节笔记中追加一条记录：

1. **本次目标**：对应 HelloAgents 的章节/小节，以及我想弄懂的概念。
2. **我的实现**：涉及哪些模块，和参考实现有什么差异。
3. **验证证据**：链接到 `tests/unit/learning/` 中的 pytest 测试，记录运行结果。
4. **疑问与失败**：真实遇到的报错、错误假设和仍未解决的问题。
5. **下一步实验**：只写一个可在本地完成的小实验，例如替换 fake LLM 的响应序列或增加一个边界用例。
